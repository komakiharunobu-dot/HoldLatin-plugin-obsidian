## 安装后的快速检查

1. 英文输入状态下短按 `c`：只输入一个 `c`。
2. 持续按住 `c` 超过 0.5 秒：弹出候选，正文没有 `c` 或 `ccccc`。
3. 继续按住 `c`，用 `1` 选择：正文只有 `ç`，不追加 `c`。
4. 松开原键后，正常打字能继续。
5. 长按 `e`，松开，再按 `x`：候选仍显示，`x` 不写入正文；按 `1` 写入 `é`。
6. 长按后按 Esc：默认写入一个原字母；按 Backspace：取消且不输入。
7. 选中一个词再选择变体，随后撤销：能恢复原词。

如其他输入增强插件也处理同一按键，请分别停用后检查，以定位冲突。
