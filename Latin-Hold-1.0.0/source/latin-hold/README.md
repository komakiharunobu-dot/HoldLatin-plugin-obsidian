# Latin Hold

**按住字母，选择变体。** 作者：komaki · 版本：1.0.0

在 Obsidian 桌面版笔记编辑器中，按住一个有候选的英文字母约 **0.5 秒**，用 **1–9** 选择法语、德语等语言的拉丁字母变体。

## 安装

1. 解压 `Latin-Hold-1.0.0.zip`。
2. 将压缩包里的 **`latin-hold` 文件夹**复制到你的仓库的 `.obsidian/plugins/` 下。不存在 `plugins` 时可以自行建立。
3. 确认实际路径是 `.obsidian/plugins/latin-hold/main.js`；`main.js`、`manifest.json`、`styles.css` 三个文件必须在同一层。不要再多套一层同名文件夹。
4. 重新启动 Obsidian，在「设置 → 第三方插件」中找到 **Latin Hold** 并启用。需要允许使用第三方插件。
5. 打开一篇 Markdown 笔记并进入编辑模式，将输入法切换到英文输入状态，长按 `e` 试用。

不需要安装 Node.js、Templater 或其他插件。压缩包的 `source/` 是供开发修改的完整源码，不是安装目录。

**macOS 找不到 `.obsidian`：** 在 Finder 打开仓库文件夹后，按 `Command + Shift + .` 显示隐藏文件夹。Windows 可在资源管理器地址栏直接进入仓库下的 `.obsidian` 路径。

本包是手动安装版本，尚未提交到 Obsidian 社区插件市场。

## 日常使用

短按字母会在松开按键时输入，**不必等待 0.5 秒**。快速打字时，即使两个按键按下的时间重叠，插件也会按顺序提交字母。

长按时，原字母暂不写入正文。到达触发时间后显示候选，松开原按键后候选仍然保留。选字期间，正文的字母、标点、数字和粘贴输入都会被拦截，直到你选择或取消；没有自动选中或超时关闭。

| 操作 | 结果 |
| --- | --- |
| 长按 `e` → `1` | `é` |
| 长按 `c` → `1` | `ç` |
| 长按 `u` → `1` | `ü` |
| 长按 `s` → `1` | `ß` |
| 长按 `Shift + c` → `1` | `Ç` |
| 长按 `Shift + s` → `1` | `ẞ` |

以上是默认「常用拉丁字母」预设的顺序。大写根据按下字母的那一刻决定，支持 Shift 和 Caps Lock。即使 Shift 尚未松开，顶行数字位置仍可用于选择。也支持数字小键盘。

选定后，若原字母键仍按着，重复事件会继续被拦截，直到松开；不会在 `ç` 后面追加 `cccc`。长按选择数字时，也不会把重复的 `1111` 写入正文。

## 选字框操作

| 按键 / 操作 | 作用 |
| --- | --- |
| `1`–`9` | 选择当前页对应的候选；不存在的序号不会写入正文 |
| `←` / `→` | 移动高亮候选 |
| `Enter` / 空格 | 插入高亮候选 |
| `Tab` / `Shift + Tab` | 下一页 / 上一页；每页重新从 1 开始编号 |
| `PageDown` / `PageUp`、`↓` / `↑` | 下一页 / 上一页 |
| `Home` / `End` | 第一个 / 最后一个候选 |
| `0` | 输入一个原始英文字母 |
| `Esc`、右上角关闭、点击外部 | 取消，默认保留一个原字母；可在设置中改成不输入 |
| `Backspace` / `Delete` | 取消且不输入，也不删除已有正文或原有选中文本 |
| 点击候选 | 插入该字母，继续在原编辑器打字 |

如果你先选中一段正文，候选确认时会替换这段选中内容。取消且不输入时，原选中内容不变。支持多光标替换，正常接入编辑器的撤销 / 重做。

选字期间普通快捷键会被拦截；要执行查找、命令面板、撤销等操作，请先按 Esc 取消。切换应用、笔记或点击编辑器外部会结束当前选择，避免留下一直锁定的输入状态。

## 设置

在「设置 → Latin Hold」中可以调整：

- **启用 / 暂停：** 也可以在命令面板搜索 `Latin Hold: 启用 / 暂停长按选字`，并在 Obsidian「快捷键」中给它绑定热键。
- **长按时间：** 默认 500 毫秒，可调 200–1500 毫秒。
- **字母范围：** 多语言常用字母，或法语、德语、西班牙语、葡萄牙语、意大利语、北欧语言、中东欧常用、土耳其语预设。
- **取消时保留原字母：** 默认开启；不影响 Backspace / Delete 和 0 的独立行为。
- **自定义候选：** 为某些字母修改顺序或增删候选。

自定义示例：

```json
{
  "e": ["é", "è", "ê", "ë"],
  "a": ["ä", "à", "á", "â", "æ"],
  "s": ["ß", "š"],
  "q": []
}
```

键名只能是小写 `a`–`z`；每个候选只能是一个拉丁字母（允许组合变音符号）。数组顺序就是显示顺序。空数组表示关闭该字母的长按。未填写的字母继续使用预设，大小写自动转换。按「保存自定义候选」后生效。

没有候选的字母（默认的 `q`，或被关闭的字母）完全保留 Obsidian 原有行为，包括系统的长按重复。

## 适用范围

- 为 **桌面版 Obsidian、实体键盘、Markdown 笔记编辑器**设计；插件声明最低 Obsidian 版本为 1.6.0。实时预览和源码模式共用 CodeMirror 6 编辑器扩展。
- 不处理阅读视图、搜索框、设置输入框、文件名或手机软键盘。
- 请在英文输入状态使用。中文、日文等输入法组字和系统死键保持输入法自己的处理；真实输入法表现仍取决于操作系统。菜单已经打开时，组合输入不能解除等待选择的锁定。
- 不支持 Vim 按键模式；使用 Vim 时请暂停本插件。与其他全局键盘拦截、输入增强插件同时使用，可能需要调整或暂停其中一个。
- 如果另一插件或同步过程在等待时更改正文或选区，本插件会取消本次待输入字符，避免在过期位置替换文字。
- 内置表是常用语言字符集合，不是完整 Unicode 字母库；可通过自定义补充需要的拉丁字母。

## 隐私与卸载

插件完全离线运行，不请求网络、不统计按键，不扫描或上传笔记。只有你确认的字符会作为普通编辑器输入写入当前笔记。设置保存在本插件的 `data.json`。

禁用或删除插件不会影响已经输入的文字：它们都是普通 Unicode 文本，不依赖插件显示。

## 开发

完整源码位于交付包的 `source/latin-hold/`。

```sh
npm install
npm run build
npm test
```

开发构建依赖 Obsidian API 1.8.7、CodeMirror 6 和 TypeScript；交付的 `main.js` 已经编译，安装用户不需要这些依赖。CodeMirror 与 Obsidian 由宿主提供，未重复打包。

核心实现：`src/engine.ts` 管理按键状态与重复拦截，`src/editor.ts` 负责编辑器事件和输入事务防护，`src/picker.ts` 显示候选，`src/variants.ts` 定义字符表。

可选模拟 DOM 集成测试（实际 CodeMirror 编辑器，模拟 DOM 事件）：

```sh
npm install --no-save jsdom@26.1.0
npm run test:dom
```

可选浏览器集成测试：

```sh
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

浏览器测试脚本用于检查原生键盘、选区、撤销、鼠标、输入锁等；不等于在完整 Obsidian 桌面应用中测试。**本次已完成 34 项核心逻辑测试和 14 项模拟 DOM 集成测试；浏览器端到端测试及完整 Obsidian 实机测试尚未完成。** 具体边界见 `TEST-REPORT.md`。

接口参考：[Obsidian 官方 API](https://github.com/obsidianmd/obsidian-api)、[CodeMirror 官方 API](https://codemirror.net/docs/ref/)。
